# Brand book

The StayBattle brand book lives at **`public/brand/index.html`** in this repo.

- **Source / repo path:** [`public/brand/index.html`](../../public/brand/index.html)
- **Public URL (after deploy):** https://staybattle.com/brand/
- **Brand assets (SVGs):** [`public/`](../../public) (`icon.svg`, `logo-banner.svg`, `logo-banner-tagline.svg`, `staybattle-main.svg`, `staybattle-main-tagline.svg`)

When referring to brand identity, colors, logo usage, tagline lockups, or asset variants, link to the public URL or to the file in `public/brand/`.

> **Sibling file:** [`staybattle-site/brand.html`](https://github.com/datboip/staybattle-site/blob/master/brand.html) in the marketing-site repo is a separate copy with absolute paths for that deployment. Keep the two in rough sync when content changes.
